STELLENBOSCH WORK CENTRE — COMBINED WEBSITE

This version combines the two supplied website versions into one integrated single-page website.

How to run:
1. Keep index.html, style.css and script.js in the same folder.
2. Open index.html in a browser.
3. Use the navigation. Pages are handled by safe hash routing, so navigation does not depend on separate HTML files.
4. AI Support is a dedicated route (#ai-support) and does not replace or corrupt the other navigation routes.

Included:
- Home, About, Services, Shop, Register, Contact and Donate
- AI Support Assistant
- Admin Overview
- Admin Registrations
- Admin Donations
- Admin Programs
- Admin Shop Products
- Responsive/mobile navigation
- Form validation and isolated interactive controls

Note:
The supplied sites contain front-end/demo data. Forms and donations are demonstration interactions and do not connect to a real database or payment gateway.
